# PropertyIQ | Real Estate Investment Portal

PropertyIQ is a sophisticated, AI-powered real estate investment analysis platform built to help investors make data-driven decisions with precision.

## 🚀 Key Features

- **AI Investment Analysis**: Leverage Genkit-powered AI to analyze property listings, identify opportunities, and assess risks.
- **Portfolio Dashboard**: Visualize portfolio performance, rental yields, and growth trends with interactive charts.
- **Financial Simulators**: 
  - **ROI Calculator**: Estimate cash-on-cash returns and annual cashflow based on purchase details.
  - **Mortgage Simulator**: Model principal and interest payments with adjustable loan parameters.
- **Market Intelligence**: Generate AI-driven market trend reports for specific regions and property types.
- **Property Directory**: Browse curated investment opportunities with high-yield potential.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **AI Engine**: [Genkit](https://github.com/firebase/genkit) with Google Gemini
- **Database & Auth**: [Firebase](https://firebase.google.com/)
- **UI Components**: [Shadcn UI](https://ui.shadcn.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Charts**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📂 Project Structure

- `src/app`: Next.js application routes and pages.
- `src/ai`: Genkit AI flows and configuration.
- `src/components`: Reusable UI components and dashboard elements.
- `src/lib`: Utility functions, mock data, and constants.
